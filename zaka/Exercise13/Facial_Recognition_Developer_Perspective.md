# Facial Recognition in Public Transport
## Developer/Company Perspective

## QUESTION 1: What is it?
**A facial recognition system installed in metro/subway systems to identify persons of interest in real time.**

### Key Points:
- System seamlessly identifies passengers using cameras to scan facial properties (similar to Face ID on Apple)
- Matches faces to passenger profiles in our secure database
- Uses deep learning to process and match faces in under a second
- Works across different lighting conditions and angles

---

## QUESTION 2: Why is it used?
**To enhance public safety by identifying suspects or preventing security threats.**

### Key Points:
- Creates seamless, fast experience - passengers don't need to show tickets
- Passengers are instantly recognized as they walk through the station
- Ensures everyone has a valid ticket, reducing fare evasion
- Makes stations safer by alerting security about persons of interest
- Deters criminals from using the transport network
- Provides data for optimizing station flow and service times

---

## QUESTION 3: Training data
**Facial image databases, security footage, and law enforcement watchlists—often trained on Western facial datasets.**

### Key Points:
- We use diverse datasets to ensure accuracy across different demographics
- Regular testing to identify and correct any bias in recognition rates
- Continuous improvement through feedback from real-world deployment
- Strict data governance and security protocols for all training data

---

## QUESTION 4: EU AI Act Considerations

### Key Points:
- High-risk system requiring human oversight and regular auditing
- We maintain complete technical documentation and risk assessments
- Alternative identification methods available for privacy-concerned users
- Regular conformity assessments and compliance checks
